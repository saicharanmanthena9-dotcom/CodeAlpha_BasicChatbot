# CodeAlpha Task 4: Basic Chatbot

A simple rule-based Python chatbot with predefined responses.

## Features
- Responds to hello, hi, hey
- Responds to "how are you"
- Responds to positive status replies
- Ends on bye/goodbye/exit/quit
- Default response for unrecognized messages

## Concepts
Functions, while loop, if-elif-else, string methods, console input/output.

## Run
```bash
python main.py
```
